# Doctoral Exam Studio

An interactive study workspace for Approximation Algorithms, Computational Complexity, and the Probabilistic Method.

**Live site:** https://hadi1373z.github.io/doctoral-exam/

## Study tools

- 33 lessons with theorem statements, proof outlines, examples, and pitfalls
- 68 automatically checked practice questions
- 13 proof reconstruction exercises
- Scheduling, sum-check, Lovász Local Lemma, and Ramsey bound labs
- Timed oral practice with a transparent self-assessment rubric
- An Expertise Map based on recorded questions, proofs, and oral assessments

The Expertise Map provides study evidence, not an official certification. Oral assessments are self-reported.

## Use and privacy

Open `index.html` in a browser, or visit the GitHub Pages link. The site has no build step, account requirement, external assets, or backend. Progress is stored in the browser on the current device. Export a JSON backup from the Expertise Map before changing devices or clearing browser data; import it to restore your records. Progress from a downloaded file and the hosted website is stored separately.

## Hosting and editing

GitHub Pages serves the `main` branch at the repository root. `.nojekyll` keeps deployment static. Edit `index.html` to update the website; the lesson, question, and proof data are included in that file.
