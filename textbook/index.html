Textbook lecture · Proof anatomy

A complete approximation argument

An approximation algorithm does not simply produce a feasible solution. Its proof compares the algorithm's objective value to the unknown optimum through a legitimate benchmark. For minimisation, the most common template is:

cost(A)≤α·LB≤α·OPT.

The benchmark LB must be proved to be at most OPT.

Worked proof: knapsack FPTAS

For items with nonnegative profits pi and capacities, discard infeasible items and let Pmax be the largest remaining profit. For 0<ε<1, take K=εPmax/n and rounded profits pi′=⌊pi/K⌋. Run the dynamic programme that finds the minimum weight for each rounded profit total.

Reveal the approximation proof

Let S⋆ be an optimal feasible set and S the rounded-profit optimum returned by DP. Because Kpi′≥pi−K,

p(S)≥Kp′(S)≥Kp′(S⋆)≥OPT−nK≥(1−ε)OPT.

The last inequality uses Pmax≤OPT. The scaled total profit is at most n⌊Pmax/K⌋=O(n2/ε), so the DP runs in time polynomial in the instance size and 1/ε.

Examiner follow-up. Why is Pmax≤OPT indispensable? What would fail if you scaled by the largest profit of an item that does not fit the knapsack?

Language and proof template

For a minimization problem, a ratio-ρ≥1\rho\geq1 algorithm satisfies ALG(I)≤ρOPT(I)\operatorname{ALG}(I)\leq\rho\operatorname{OPT}(I). For a maximization problem it is often cleaner to use a guarantee 0<α≤10<\alpha\leq1 and write ALG(I)≥αOPT(I)\operatorname{ALG}(I)\geq\alpha\operatorname{OPT}(I). Do not silently switch between the conventions α\alpha and 1/α1/\alpha.

A PTAS gives a (1+ε)(1+\varepsilon)-approximation for minimization, or a (1−ε)(1-\varepsilon)-approximation for maximization, in polynomial time for each fixed ε>0\varepsilon>0. An FPTAS is polynomial in both the input length and 1/ε1/\varepsilon. An APTAS may have an additive constant, for example ALG≤(1+ε)OPT+1\operatorname{ALG}\leq(1+\varepsilon)\operatorname{OPT}+1. A pseudo-polynomial algorithm is polynomial in numerical values rather than their binary encoding lengths.

Every approximation proof has four logically separate parts: (i) the output is feasible; (ii) a lower/upper benchmark bounds OPT\operatorname{OPT}; (iii) the algorithm is compared with that benchmark; (iv) the running time is polynomial in the required parameters.

For a relaxation, remember the direction: OPTLP≤OPTintfor minimization,OPTLP≥OPTintfor maximization.\operatorname{OPT}_{\mathrm LP}\leq\operatorname{OPT}_{\mathrm int}\quad\text{for minimization}, \qquad \operatorname{OPT}_{\mathrm LP}\geq\operatorname{OPT}_{\mathrm int}\quad\text{for maximization}. The integrality gap limits what can be proved by rounding that particular relaxation.

Identical-machine makespan: a PTAS (Section 3.2)

For P||CmaxP||C_{\max}, useful lower bounds are OPT≥maxjpj,OPT≥1m∑jpj.\operatorname{OPT}\geq\max_jp_j, \qquad \operatorname{OPT}\geq\frac1m\sum_jp_j. For a guessed target TT, classify jobs as large or small relative to εT\varepsilon T. There are at most m/εm/\varepsilon large jobs in any schedule of makespan TT. Round their processing times to a constant number of sizes, enumerate or dynamically program over feasible machine configurations, and place the small jobs greedily on least-loaded machines.

Bin packing: an APTAS (Section 3.3)

Normalize bin capacity to one. Separate small items from large items. Sort the large items and apply linear grouping: partition them into groups of equal cardinality, set aside the first (largest) group, and round every size in each later group up to the largest size of that group. Only constantly many rounded sizes remain, so a dynamic program can optimize the rounded configurations.

The rounded solution is feasible for the original large items because sizes were rounded up. The discarded first group costs only O(εOPT)+O(1)O(\varepsilon\operatorname{OPT})+O(1) extra bins. Insert small items greedily; if a new bin is opened, all previous bins have load close to one. The resulting guarantee is of the form ALG(I)≤(1+ε)OPT(I)+1.\operatorname{ALG}(I)\leq(1+\varepsilon)\operatorname{OPT}(I)+1. The additive one is why the result is an asymptotic PTAS rather than an ordinary PTAS.

Direct gap reductions (Section 16.1)

A gap reduction maps an NP-complete instance xx to an optimization instance IxI_x so that x∈L⇒OPT(Ix)≤a,x∉L⇒OPT(Ix)≥bx\in L\Rightarrow\operatorname{OPT}(I_x)\leq a,\qquad x\notin L\Rightarrow\operatorname{OPT}(I_x)\geq b for minimization (reverse the inequalities for maximization). Any ratio strictly better than b/ab/a distinguishes the cases.

The section’s main example reduces 3-dimensional matching to makespan scheduling on unrelated parallel machines. The construction creates element jobs, triple machines, and dummy jobs so that a perfect 3-dimensional matching yields a schedule of length two, whereas every schedule for a NO instance has length at least three. Consequently, unless P=NPP=NP, there is no (3/2−ε)(3/2-\varepsilon)-approximation for any fixed ε>0\varepsilon>0. The proof must establish both directions of the gap; mere NP-hardness of computing OPT\operatorname{OPT} gives no approximation lower bound.

PCP reductions (Section 16.3)

L∈PCPc,s(r(n),q(n))L\in\mathrm{PCP}_{c,s}(r(n),q(n)) means that a randomized polynomial-time verifier uses at most r(n)r(n) random bits, reads at most q(n)q(n) locations of a proof π\pi, and satisfies x∈L⇒∃π:Pr[Vπ(x)=1]≥c,qquadx∉L⇒∀π:Pr[Vπ(x)=1]≤s.x\in L\Rightarrow\exists\pi:\Pr[V^\pi(x)=1]\geq c,qquad x\notin L\Rightarrow\forall\pi:\Pr[V^\pi(x)=1]\leq s. The PCP theorem gives 𝖭𝖯=PCP(O(logn),O(1))\mathsf{NP}=\mathrm{PCP}(O(\log n),O(1)) with a constant completeness–soundness gap.

To obtain an optimization instance, create one constant-arity constraint for every verifier random string; its variables are the proof locations queried on that string. If the verifier has perfect completeness, a YES instance satisfies all constraints. For a NO instance, every assignment satisfies at most an ss fraction. Thus a PCP is exactly a source of a robust gap rather than merely an NP witness verifier.

The refined three-query construction in the section yields MAX-E3SAT hardness: for every constant δ>0\delta>0 it is NP-hard to distinguish a satisfiable instance from one in which at most a (7/8+δ)(7/8+\delta) fraction of clauses can be satisfied. Hence, for any constant α>7/8\alpha>7/8, an α\alpha-approximation for MAX-E3SAT would imply P=NPP=NP. This matches the 7/87/8 random-assignment algorithm up to an arbitrarily small additive constant.

Why every interactive proof is in PSPACE

Take an interactive verifier using R random bits and at most a polynomial number of messages, padded to fixed lengths. The prover can see only the public transcript, never the verifier's private random tape. This observation is the delicate part of the upper bound.

State of the dynamic program

For each public transcript h, consider the verifier tapes consistent with it. At a complete transcript, let A(h) count the accepting-consistent tapes. Define a backward recursion Val(h) on transcript prefixes.

Terminal: Val(h)=A(h)Prover turn: Val(h)=maxaVal(ha)Verifier turn: Val(h)=∑bVal(hb)

Proof of correctness

Induct backwards on the number of remaining messages. At a prover node all random tapes sharing a visible transcript must receive the same prover message, so one takes a maximum over messages. At a verifier node the next public message partitions the consistent tapes into disjoint classes, so one sums their optimal continuation counts. At a leaf one counts accepting tapes by enumeration. It follows that Val(ε)/2R is exactly the maximum acceptance probability over prover strategies.

Space bound

The recursion depth, transcript length, and counter bit length are polynomial in the input size. Enumerating exponentially many messages and random tapes costs time but not more than polynomial space. Depth-first evaluation therefore decides the language in polynomial space.

Common incorrect proof. Maximising separately for each verifier random string lets the prover learn private coins. The correct recursion maximises only over messages that depend on the public transcript.

Fix the input. A deterministic strategy for each prover is a table mapping its polynomial-length local transcripts to polynomial-length answers. 𝖭𝖤𝖷𝖯⊆𝖬𝖨𝖯\mathsf{NEXP}\subseteq\mathsf{MIP}: proof architecture

An 𝖭𝖤𝖷𝖯\mathsf{NEXP} computation has an exponentially long tableau or witness, while every location still has a polynomial-length address. The lower-bound proof has four separate stages.

  1. Encode the accepting computation by a Boolean function on m=poly(n)m=\operatorname{poly}(n) address bits and extend it to the unique multilinear polynomial over a sufficiently large finite field.

  2. Arithmetize the local transition constraints. A false tableau makes the resulting constraint polynomial nonzero; an LFKN-style reduction turns the claim that its global sum is zero into claims about values at random points.

  3. Replace trusted oracle access by two noncommunicating provers. Correlated questions compare their answers, while the multilinearity test checks that the alleged value table behaves like one multilinear function rather than unrelated answers chosen separately at each query.

  4. For soundness, first condition on passing the multilinearity and consistency tests. The answers are then close to evaluations of a single multilinear polynomial. If no accepting tableau exists, the arithmetized constraint is nonzero, so the random algebraic check catches the lie with constant probability. Standard repetition reduces the remaining error.

The essential role of the second prover is therefore not extra computation: it is the enforcement of one globally consistent function behind locally requested values. This yields 𝖬𝖨𝖯=𝖭𝖤𝖷𝖯.\boxed{\mathsf{MIP}=\mathsf{NEXP}.}

Warm-up: graph isomorphism

For isomorphic G0,G1G_0,G_1, the prover sends a random relabeling HH of one graph. The verifier sends a challenge b∈{0,1}b\in\{0,1\}, and the prover opens an isomorphism Gb≅HG_b\cong H. Each attempt succeeds with probability 1/21/2, and conditioned on success the transcript has the correct distribution. Rewinding is the central simulation technique.

The GMW protocol for 3-colouring

Let c:V→{1,2,3}c:V\to\{1,2,3\} be a proper colouring and let the commitment scheme be hiding and binding.

  1. The prover chooses a random permutation π\pi of the three colours and commits separately to every value π(c(v))\pi(c(v)).

  2. The verifier chooses a uniformly random edge uvuv.

  3. The prover opens only the two endpoint commitments; the verifier checks that the openings are valid and the colours differ.

Perfect completeness is immediate. If the graph is not 3-colourable, every fixed committed assignment has a monochromatic edge; binding prevents changing it after the challenge. A round therefore rejects with probability at least 1/|E|1/|E|, and sequential repetition gives constant or negligible soundness error.

For a malicious verifier V*V^* with arbitrary auxiliary input, the simulator uses the following rewinding experiment.

  1. Guess an edge e=uve=uv uniformly from EE and choose an ordered pair of distinct colours uniformly from the six possibilities.

  2. Commit to those colours at u,vu,v and commit to arbitrary dummy colours at all other vertices; run V*V^* on these commitments with a fixed sampled random tape.

  3. If V*V^* asks for an edge different from ee, discard the attempt and restart. Otherwise open the two commitments and output the complete view.

For the honest verifier, the guessed edge matches with probability exactly 1/|E|1/|E|. For a malicious V*V^*, its challenge may depend on the commitment string, so exact uniformity must not be assumed. Instead, computational hiding makes the challenge distribution computationally insensitive to which edge was prepared. The success probability is therefore inverse-polynomial, up to a negligible term, and rewinding has expected polynomial running time (with the standard cutoff if one wants a strict polynomial-time simulator). Conditioned on success, the opened ordered pair is uniform over the six distinct colour pairs, exactly as for a uniformly permuted proper colouring. The unopened commitments need not encode a global colouring; a hybrid argument using computational hiding replaces their dummy messages one at a time by the real committed colours. Thus the simulated and real views are computationally indistinguishable. Binding, separately, prevents a cheating prover from adapting endpoint colours after seeing the edge. Via reductions to 3-colouring, GMW obtains zero-knowledge proofs for all of 𝖭𝖯\mathsf{NP} from the stated commitment/encryption assumption.

Do not conflate properties. Binding supports soundness; hiding supports zero knowledge. Zero knowledge does not mean that the verifier learns nothing at all—it learns that the statement is true. Sequential composition is the safe default under standard hypotheses; arbitrary parallel repetition need not preserve zero knowledge.

Lattices, monotonicity, and the Four Functions Theorem

A finite lattice (L,≤)(L,\leq) has a meet x∧yx\wedge y and join x∨yx\vee y. It is distributive when meet and join distribute over each other. The main example is L=2[n]L=2^{[n]} ordered by inclusion, with A∧B=A∩BA\wedge B=A\cap B and A∨B=A∪BA\vee B=A\cup B. A function f:L→ℝf:L\to\mathbb R is increasing if x≤yx\leq y implies f(x)≤f(y)f(x)\leq f(y).

For nonnegative α,β,γ,δ:L→ℝ≥0\alpha,\beta,\gamma,\delta:L\to\mathbb R_{\geq0}, suppose α(x)β(y)≤γ(x∨y)δ(x∧y)for all x,y∈L.\alpha(x)\beta(y)\leq\gamma(x\vee y)\delta(x\wedge y) \qquad\text{for all }x,y\in L. \tag{4F-local} Writing α(𝒜)=∑x∈𝒜α(x)\alpha(\mathcal A)=\sum_{x\in\mathcal A}\alpha(x) and 𝒜∨ℬ={x∨y:x∈𝒜,y∈ℬ},𝒜∧ℬ={x∧y:x∈𝒜,y∈ℬ},\mathcal A\vee\mathcal B=\{x\vee y:x\in\mathcal A,y\in\mathcal B\}, \qquad \mathcal A\wedge\mathcal B=\{x\wedge y:x\in\mathcal A,y\in\mathcal B\}, the Ahlswede–Daykin Four Functions Theorem gives α(𝒜)β(ℬ)≤γ(𝒜∨ℬ)δ(𝒜∧ℬ).\alpha(\mathcal A)\beta(\mathcal B) \leq\gamma(\mathcal A\vee\mathcal B) \delta(\mathcal A\wedge\mathcal B). \tag{4F-global} The striking point is that a pointwise lattice inequality survives summation. FKG and Harris–Kleitman

A nonnegative weight μ:L→ℝ≥0\mu:L\to\mathbb R_{\geq0} is log-supermodular if μ(x∨y)μ(x∧y)≥μ(x)μ(y).\mu(x\vee y)\mu(x\wedge y)\geq\mu(x)\mu(y). After normalization, regard μ\mu as a probability distribution. The FKG inequality states that for increasing f,g:L→ℝf,g:L\to\mathbb R, 𝔼μ[fg]≥𝔼μ[f]𝔼μ[g].\mathbb E_\mu[fg]\geq\mathbb E_\mu[f]\,\mathbb E_\mu[g]. \tag{FKG} For increasing events A,BA,B, take indicator functions: ℙμ(A∩B)≥ℙμ(A)ℙμ(B).\mathbb P_\mu(A\cap B)\geq\mathbb P_\mu(A)\mathbb P_\mu(B). Proof route: combine log-supermodularity of μ\mu and monotonicity of f,gf,g to form four functions satisfying (4F-local), apply Four Functions, and normalize.

For independent coordinates, the product measure on 2[n]2^{[n]} has μ(S)=∏i∈Spi∏i∉S(1−pi)⇒μ(A∪B)μ(A∩B)=μ(A)μ(B).\mu(S)=\prod_{i\in S}p_i\prod_{i\notin S}(1-p_i) \quad\Longrightarrow\quad \mu(A\cup B)\mu(A\cap B)=\mu(A)\mu(B). If AA is increasing and DD is decreasing, then DcD^c is increasing and ℙ(A∩D)≤ℙ(A)ℙ(D).\mathbb P(A\cap D)\leq\mathbb P(A)\mathbb P(D).

Graph-property application. In G(n,p)G(n,p), containing a Hamilton cycle and being connected are increasing; planarity and being triangle-free are decreasing. The XYZ theorem for linear extensions

Choose a linear extension of a finite poset PP uniformly. For any elements x,y,zx,y,z (where x<yx<y denotes that xx precedes yy in the random extension), ℙ[x<y∧x<z]≥ℙ[x<y]ℙ[x<z].\mathbb P[x<y\ \wedge\ x<z]\geq \mathbb P[x<y]\mathbb P[x<z]. \tag{XYZ} The proof embeds order-preserving integer labelings into a carefully chosen finite distributive lattice. The set of labelings has a log-supermodular indicator, while the two order events are increasing. Apply FKG and let the label range tend to infinity; ties become negligible, leaving uniform linear extensions. The lesson is not that arbitrary order events correlate positively: the lattice order and monotonicity must be verified.

Correlation checklist: identify the lattice; determine which events/functions are increasing; verify log-supermodularity; apply FKG; reverse the sign by complementing exactly one increasing event. Never infer correlation merely from a verbal intuition that two events are both likely.

Binary entropy and volumes

For p∈(0,1)p\in(0,1), the binary entropy is H(p)=−plog2p−(1−p)log2(1−p).H(p)=-p\log_2p-(1-p)\log_2(1-p). For fixed 0<p<1/20<p<1/2, ∑i≤pn(ni)=2H(p)n+o(n).\sum_{i\leq pn}\binom ni=2^{H(p)n+o(n)}. This is the exponential size of a Hamming ball of relative radius pp. Whenever a coding bound contains 1−H(p)1-H(p), it comes from the exponent 2n/2H(p)n2^n/2^{H(p)n}: the ambient cube divided by the effective error-ball volume.

Shannon’s theorem by random coding

In the binary symmetric channel BSC(p)\operatorname{BSC}(p), every transmitted bit is independently flipped with probability p<1/2p<1/2. A code with M=2RnM=2^{Rn} length-nn codewords has rate RR. Shannon’s theorem says that for every ε>0\varepsilon>0 there are schemes of rate R>1−H(p)−εR>1-H(p)-\varepsilon with decoding error below ε\varepsilon for sufficiently large nn.

Proof skeleton: select codewords randomly and decode to the unique codeword within Hamming distance (p+η)n(p+\eta)n when one exists. Chernoff bounds make the actual error pattern atypically large with probability o(1)o(1). The ball bound gives at most 2H(p+η)n2^{H(p+\eta)n} plausible received strings around a competitor. A union bound over M−1M-1 competitors is exponentially small when R+H(p+η)<1.R+H(p+\eta)<1. Averaging supplies a deterministic code. Random linear/group codes use the same collision calculation while giving a succinct algebraic encoder. The converse direction says a rate above 1−H(p)+ε1-H(p)+\varepsilon must retain significant error; capacity is therefore 1−H(p)1-H(p).

The liar game and the sphere bound

Paul must identify one of nn possibilities using qq yes/no questions while Carole may lie at most kk times. A truthful answer string has V(q,k)=∑j=0k(qj)V(q,k)=\sum_{j=0}^k\binom qj strings within kk lies. Distinguishability therefore requires the Hamming sphere bound nV(q,k)≤2q.nV(q,k)\leq2^q. \tag{sphere bound}

In the ChipLiar formulation, let xix_i be the number of chips that can tolerate ii further lies and put B(q,i)=2−q∑j=0i(qj).B(q,i)=2^{-q}\sum_{j=0}^i\binom qj. This is a clean example of using a random strategy to prove that an adversarial player has a deterministic winning strategy.

Balancing, tenure, and online viewpoints

In the balancing game, Pusher proposes a sign vector and Chooser selects its global sign. A potential based on random-walk tail probabilities makes the two successor potentials average to the current one. Chooser selects the smaller potential for an upper bound; Pusher selects coordinates to keep the two successors close for a lower bound. This yields the scale VAL(n)=Θ(nlogn).\operatorname{VAL}(n)=\Theta(\sqrt{n\log n}). The nonadaptive/online discrepancy interpretation is that columns arrive one at a time and their signs must be fixed irrevocably. The half-liar game changes the allowed direction of a lie, so ordinary symmetric Hamming balls no longer describe the state space; the weighted decision-tree argument must respect the asymmetry. Across these games the invariant is the same: define a potential whose average over the opponent’s two moves is controlled.

Dense-graph model and definitions

The input is an nn-vertex graph accessed through adjacency queries: "is uvuv an edge?" Testing kk-colourability

Triangle-freeness and the removal lemma

The triangle-removal lemma says that for every ε>0\varepsilon>0 there is δ(ε)>0\delta(\varepsilon)>0 such that any nn-vertex graph that is ε\varepsilon-far from triangle-free contains at least δ(ε)n3\delta(\varepsilon)n^3 triangles. Its proof uses Szemerédi regularity: delete edges incident with the exceptional class, inside parts, in irregular pairs, and in low-density regular pairs. If fewer than εn2\varepsilon n^2 edges were deleted, one triangle remains among three dense regular pairs; the counting argument then produces δn3\delta n^3 triangles in the original graph.

The tester samples uniform triples and rejects if one spans a triangle. It never rejects a triangle-free graph. If GG is far, a random ordered triple is a triangle with probability Ω(δ)\Omega(\delta), so O(1/δ(ε))O(1/\delta(\varepsilon)) independent trials give constant rejection probability. Equivalently, sample a constant-size vertex set and query all pairs. The dependence on ε\varepsilon is enormous because the regularity lemma is quantitative, but it is independent of nn.

Hereditary properties

A graph property is hereditary if it is closed under deleting vertices; equivalently, it is characterized by a possibly infinite collection of forbidden induced subgraphs. Perfectness, chordality, and being an interval graph are hereditary; a hereditary property need not be monotone under edge deletion.

The induced-removal theorem implies that every hereditary graph property is testable with one-sided error in the dense model. For every ε>0\varepsilon>0 there is q=q𝒫(ε)q=q_{\mathcal P}(\varepsilon) such that if GG is ε\varepsilon-far from 𝒫\mathcal P, then a uniform induced qq-vertex subgraph violates 𝒫\mathcal P with constant probability. The tester samples qq vertices, queries all (q2)\binom q2 pairs, and checks the induced graph. The distinction between ordinary and induced copies is essential: edge-monotone properties use ordinary removal; hereditary properties require induced removal.
