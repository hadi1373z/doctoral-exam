§3.1 · Knapsack: an FPTAS with a full bit-complexity argument

Profit-indexed dynamic programming is pseudo-polynomial; scaling profits with K=εPmax/n yields a feasible solution worth at least (1−ε)OPT in polynomial time in n and 1/ε.

Construction and proof obligations

  1. Discard items heavier than capacity; set Pmax to the largest remaining profit.
  2. Set p′ᵢ=⌊pᵢ/K⌋; minimize weight for each total scaled profit.
  3. Compare the rounded objective of the optimum with that of the computed solution.
  4. Bound loss by nK≤εOPT and count DP states and arithmetic bits.

At the board

1. Get a computable lower bound

Remove items heavier than the capacity W. If no positive-profit feasible item remains, the empty set is optimal. Otherwise let P be the largest remaining profit. A single best item is feasible, and no solution uses more than n items.

P≤OPT≤nP,K=εPn,pi′=⌊piK⌋.P\leq\mathrm{OPT}\leq nP,\qquad K=\frac{\varepsilon P}{n},\qquad p'_i=\left\lfloor\frac{p_i}{K}\right\rfloor.

2. Keep exact weights in the dynamic program

Let Dᵢ(q) be the minimum original weight of a subset of the first i items with scaled profit q; impossible states have value infinity. Initialize D₀(0)=0. For each item use the better of skipping it and adding its original weight. Return a feasible state with maximum scaled profit. Feasibility is exact because weights were never rounded.

Di(q)=min⁡{Di−1(q), wi+Di−1(q−pi′)}.D_i(q)=\min\{D_{i-1}(q),\ w_i+D_{i-1}(q-p'_i)\}.

3. Compare to an optimum in the rounded objective

For an original optimum O and the returned set S, the DP maximizes scaled profit among all feasible subsets. The floor loses less than K per item, so transferring back to original profits loses at most nK.

p(S)≥Kp′(S)≥Kp′(O)≥p(O)−nK≥(1−ε)OPT.p(S)\geq Kp'(S)\geq Kp'(O)\geq p(O)-nK\geq(1-\varepsilon)\mathrm{OPT}.

4. Count states in terms of input length

Every remaining item has profit at most P, so its scaled profit is at most n/ε. The total scaled-profit range is at most n²/ε. The elementary DP therefore has O(n³/ε) transitions. Stored weights are sums of at most n binary inputs and require only polynomially many bits; rational scale arithmetic also uses polynomial bit length.

∑ipi′≤n2ε,T=O(n3/ε).\sum_i p'_i\leq\frac{n^2}{\varepsilon},\qquad T=O(n^3/\varepsilon).

5. Identify what would break the proof

Scaling weights could make a selected set infeasible after restoration. A DP polynomial in the numerical capacity W need not be polynomial in its binary input length. The FPTAS requires polynomial dependence jointly on input size and 1/ε, not merely polynomial time for each fixed ε.

Examiner task

Construct the profit-scaling algorithm from scratch. Prove feasibility, the multiplicative guarantee and polynomial bit complexity. Explain why a DP polynomial in the numerical capacity is insufficient.

Why not scale using an unknown OPT?

Use the computable Pmax, which lies between OPT/n and OPT after infeasible items are removed.

Can an FPTAS have running time n^(1/ε)?

No. That is polynomial for fixed ε, but not polynomial jointly in input size and 1/ε.

§3.2 · Scheduling schemes: large jobs, rounded types, configurations

Identical-machine makespan scheduling admits a PTAS by rounding large jobs and placing the small jobs after solving a bounded-type configuration problem.

Construction and proof obligations

  1. Guess a target makespan T and use a lower bound on OPT.
  2. Separate jobs at εT; round large processing times upward on a controlled grid.
  3. Enumerate feasible machine configurations or use the section’s bounded-type DP.
  4. Insert the small jobs on least-loaded machines and charge the last-job overshoot.

At the board

If pᵢ>εT, a T-load machine has fewer than 1/ε such jobs. Rounding to multiples of ε²T increases its large-job load by at most εT.

A machine configuration records counts of rounded types, not item identities. With ε fixed, the family of configurations is bounded independently of n.

If a small job of length at most εT is placed last, its start time is at most total load/m≤T whenever a T-schedule exists; its completion is at most (1+ε)T. Combine this with the rounding slack and rescale the internal ε.

Examiner task

Design a dual-approximation feasibility test for a proposed T. Bound the number of large-job types and configurations, prove the rounding loss and small-job insertion bound, then state exactly which parameters are fixed for polynomial time.

What fails for unrelated machines?

A job has a different length on each machine; the identical-type compression and common average-load argument no longer give this proof.

Does a large exponent depending on ε give an FPTAS?

It gives a PTAS only. Keep the distinction between n^(f(1/ε)) and poly(n,1/ε) explicit.

§3.3 · Bin packing: linear grouping and the additive term

Grouping and rounding large items gives an asymptotic approximation scheme; the guarantee must retain its additive-bin term.

Construction and proof obligations

  1. Separate items of size at least ε.
  2. Sort large items and group them into equal-cardinality blocks.
  3. Pack the rounded instance by configurations and charge the discarded largest block separately.
  4. Insert small items and analyze the nearly full bins.

At the board

Rounding one block upward can be charged to the preceding block’s larger items; explicitly match items between adjacent blocks. The largest block is treated separately.

If a new bin is opened while placing an item smaller than ε, the earlier bins have load above 1−ε. Their count is controlled by total size/(1−ε).

For a partition instance of total size 2 with each item at most 1, OPT=2 exactly when a two-bin packing exists. An absolute ratio strictly below 3/2 must output an integer number of bins below 3 on YES instances.

Examiner task

Reconstruct the linear-grouping injection that compares the rounded instance with OPT. Derive an asymptotic (1+O(ε))OPT+O(1) bound. Then prove why an absolute ratio below 3/2 would solve a two-bin partition decision problem.

Why can an APTAS coexist with this hardness?

Its additive constant can matter when OPT=2; asymptotic and absolute guarantees have different quantifiers.

Is a total-volume lower bound sufficient to pack items?

No. Three items of size 0.6 have total 1.8 but need three unit bins.

§§5.1–5.3 · Random and biased assignments; derandomization

An independent fair assignment satisfies a k-literal non-tautological clause on distinct variables with probability 1−2^−k. Conditional expectation converts a computable expectation guarantee into a deterministic one.

Construction and proof obligations

  1. Express weighted satisfaction as a sum of indicators.
  2. Calculate clause failure under the chosen marginal probabilities.
  3. Maintain the conditional expected objective for a partial assignment.
  4. Choose the next bit with the larger conditional expectation.

At the board

For independent marginals yᵢ, a clause fails with probability ∏positive(1−yᵢ)∏negative yᵢ. The conditional expression drops assigned false literals and becomes zero failure once a literal is true.

At a fair next bit, E[X|prefix] is the average of its two child expectations; choose a child at least as large. Recompute clause contributions in polynomial time.

A common bias improves positive unit clauses while harming negative ones. A guarantee must analyze the actual literal pattern; it cannot simply substitute p into 1−(1−p)^k for every clause.

Examiner task

Give a weighted MAX-SAT instance with both unit and long clauses. Compute the conditional-expectation update exactly, derive the length-dependent ratio, and explain the limitation of one common biased coin when negative literals are present.

Where is independence used?

Only to multiply the within-clause failure probabilities. Linearity of expectation needs no independence between clauses.

What is a certificate for the final deterministic guarantee?

A monotone sequence of conditional expectations ending at the actual integral objective.

§§5.4–5.5 · MAX-SAT: LP rounding and the better-of-two 3/4 guarantee

Independent LP-marginal rounding gives 1−1/e; choosing the better of fair and LP rounding gives a 3/4 approximation, by a clausewise comparison with the same LP benchmark.

Construction and proof obligations

  1. Normalize clauses and solve the MAX-SAT LP with zC≤sum of literal marginals and zC≤1.
  2. Independently set each variable true with its LP marginal; bound a k-literal clause by (1−(1−1/k)^k)zC.
  3. A fair assignment satisfies that clause with probability 1−2^(−k)≥(1−2^(−k))zC.
  4. For every k≥1, half the sum of these two coefficients is at least 3/4; sum by clause weight and take the better assignment.

At the board

Step 1

Normalize clauses and solve the MAX-SAT LP with zC≤sum of literal marginals and zC≤1.

Step 2

Independently set each variable true with its LP marginal; bound a k-literal clause by (1−(1−1/k)^k)zC.

Step 3

A fair assignment satisfies that clause with probability 1−2^(−k)≥(1−2^(−k))zC.

Step 4

For every k≥1, half the sum of these two coefficients is at least 3/4; sum by clause weight and take the better assignment.

Check the 3/4 comparison

For k=1 the two coefficients are 1/2 and 1; for k=2 they are 3/4 and 3/4. For k≥3, 1−2^(−k)≥7/8 and 1−(1−1/k)^k≥1−1/e, whose sum exceeds 3/2. The maximum of two objective values is at least their mean.

max⁡{EWF,EWL}≥12(EWF+EWL)≥34∑CwCzC≥34OPT.\max\{\mathbb E W_F,\mathbb E W_L\}\ge\tfrac12(\mathbb E W_F+\mathbb E W_L)\ge\tfrac34\sum_Cw_Cz_C\ge\tfrac34\mathrm{OPT}.

Examiner task

Derive the LP-rounding clause bound with AM–GM, then prove the better-of-two 3/4 guarantee clause by clause. Explain why averaging 1/2 and 1−1/e is too weak and why the same LP objective is necessary.

Why is the LP a correct benchmark for maximization?

Every Boolean assignment is LP-feasible, so LP optimum upper-bounds integral OPT.

Can correlations between repeated literals invalidate AM–GM?

Yes. Normalize clauses to remove repeated variables and tautologies before using the independent-literal product.

§§6.1–6.2 · Gram matrices and the exact MAX-CUT ratio

A PSD matrix with unit diagonal is a Gram matrix of unit vectors. Hyperplane rounding gives separation probability θ/π and the Goemans–Williamson factor minθ 2θ/[π(1−cos θ)]≈0.87856.

Construction and proof obligations

  1. Convert a sign quadratic objective to a PSD Gram-matrix program.
  2. Factor a feasible matrix to vectors.
  3. Calculate angular separation under a uniform hyperplane.
  4. Prove an edgewise comparison and sum with nonnegative weights.

At the board

For integral signs, Xᵢⱼ=sᵢsⱼ; dropping rank one leaves X≽0 and Xᵢᵢ=1. The relaxed objective is an upper bound for maximization.

Rotational symmetry reduces an edge to a plane; the separating normal directions occupy angular measure 2θ out of 2π, giving θ/π.

The stationary equation is 1−cos θ=θ sin θ. Compare both sides edgewise; multiplication by a negative weight reverses an inequality, so the standard nonnegative-weight hypothesis matters.

Examiner task

Derive the SDP and the angle probability without invoking the algorithm’s name. Characterize an interior minimizer of the ratio. Explain why negative edge weights invalidate this edgewise summation proof.

Can a numerically tiny negative eigenvalue be ignored in a rigorous proof?

A certified or appropriately repaired PSD solution and optimization tolerance are needed; exact feasibility and floating-point output are different claims.

Does the SDP optimum equal OPT?

Not generally. It is an upper bound and can have a nontrivial integrality gap.

§6.5 · Vector coloring, semicoloring, and the 0.387 exponent

A 3-coloring embeds in three unit vectors with edge inner product −1/2. Multiple hyperplanes yield semicolorings; balancing high-degree removal against low-degree rounding gives the section’s exponent.

Construction and proof obligations

  1. Construct the equilateral-triangle vector solution.
  2. Bound the collision probability after t independent hyperplanes by 3^−t.
  3. Delete endpoints of monochromatic edges to retain a properly colored constant fraction.
  4. Balance n/σ against σ^(log₃2), then iterate semicolorings.

At the board

An edge has angle at least 2π/3, so a hyperplane fails to separate it with probability at most 1/3. After t=⌈2+log₃Δ⌉ planes, sum collision indicators over at most nΔ/2 edges.

Markov bounds the chance of too many monochromatic edges. Removing their endpoints leaves at least a constant fraction properly colored, which is enough for recursive semicoloring.

Writing a=log₃2, choose σ=n^(1/(1+a)); the exponent a/(1+a)=log₆2≈0.38685. Repeating on the remaining vertices adds a logarithmic color factor.

Examiner task

Derive the semicoloring probability and color count from first principles. Solve n/σ=σ^(log₃2), explain the approximately 0.387 exponent, and account for the logarithmic factor needed to color every vertex.

Why is a vector 3-coloring not an actual 3-coloring?

The relaxation imposes pairwise angular inequalities, not a partition into three discrete classes.

Can one use the same palette at every recursive round?

No guarantee prevents edges between rounds from becoming monochromatic. Use disjoint palettes in this construction.

§13.2 · Gaussian threshold rounding for independent sets

The section’s Gaussian-vector algorithm extracts an independent set of expected size Ω(nΔ^−1/3(ln Δ)^−1/2) from a promised 3-colorable graph.

Construction and proof obligations

  1. Choose a standard Gaussian direction and retain vertices above a threshold.
  2. Use the negative edge correlations of the vector solution.
  3. Bound retained vertices and retained edges using Gaussian tails.
  4. Delete one endpoint per retained edge and optimize the threshold.

At the board

A unit vector dotted with a standard Gaussian is N(0,1). An edge’s two projections are jointly Gaussian with correlation at most −1/2.

If both projections exceed t, their sum exceeds 2t, while the sum variance is at most 1. This makes adjacent co-selection much rarer than single-vertex selection.

The expected independent-set size is at least the expected selected vertices minus the expected selected edges. Optimizing the Gaussian threshold yields the stated Δ^−1/3 factor with the tail prefactor involving √ln Δ.

Examiner task

Derive the one-vertex and two-adjacent-vertex tail estimates used by the algorithm. Optimize the threshold so the expected repair cost is smaller than the retained mass, retaining logarithmic factors rather than hiding them prematurely.

Why is this not independent vertex sampling?

All vertex choices use one Gaussian direction and are correlated; the useful negative correlation comes from the SDP geometry.

What changes when Δ is bounded by a small constant?

Use a separate constant-size-degree argument rather than treating ln Δ at Δ=1 as a valid asymptotic formula.

§7.1 · Primal–dual set cover: tight sets and frequency

Raising uncovered-element dual variables until sets become tight gives an f-approximation when each element belongs to at most f sets.

Construction and proof obligations

  1. Write min∑cSxS and max∑yᵤ with ∑u∈S yᵤ≤cS.
  2. Raise an uncovered element’s y until a containing set becomes tight.
  3. Buy a tight set and maintain dual feasibility.
  4. Expand bought-set cost as a sum of dual charges; bound each multiplicity by f.

At the board

Every purchased set is tight, so ∑bought cS=∑ᵤ yᵤ·|{bought S:u∈S}|≤f∑ᵤyᵤ.

Weak duality gives ∑ᵤyᵤ≤OPT. Termination covers all elements provided the instance is coverable.

The bound is incidence frequency per element, not size per set. A set’s cardinality can be small while an element occurs in very many sets.

Examiner task

Prove primal feasibility, dual feasibility and the f factor. Construct the charging expression explicitly and explain why replacing f by the maximum set cardinality is unjustified.

Why stop increasing a dual variable when a set gets tight?

Further growth could violate its dual constraint, destroying the lower-bound certificate.

Does greedy’s Hn analysis automatically prove this algorithm’s ratio?

No. Greedy charging and dual tight-set charging are distinct analyses.

§7.3 · Shortest path: why reverse deletion is essential

A primal–dual cut-growing procedure yields an exact shortest s–t path after redundant tight edges are removed.

Construction and proof obligations

  1. Use s–t separating cuts as dual variables.
  2. Grow the cut separating the current reachable region from t.
  3. Add edges when their reduced slack reaches zero.
  4. Delete redundant edges and show each positive dual cut is crossed once by the final path.

At the board

Tightness alone gives cost as a sum of dual variables weighted by cut-crossing multiplicities. Exactness requires those multiplicities to be one on the final path.

Reachable regions form nested s-side cuts. Reverse deletion removes branches that are not needed to connect s to t.

For the surviving path P, ∑e∈P cₑ=∑S yS|P∩δ(S)|=∑S yS≤OPT. Feasibility gives the reverse inequality and proves optimality.

Examiner task

Write the path cut relaxation and its dual. Give an example where the whole collection of tight edges is unnecessarily expensive. Prove that the pruned path crosses every raised cut once and consequently has cost equal to the dual objective.

Why does an arbitrary tight connected subgraph not suffice?

It may pay for extra branches and cross a positive dual cut more than once.

Where is the final equality stronger than an approximation proof?

Each dual charge is counted exactly once, rather than at most a constant number of times.

§7.4 · Generalized Steiner tree: moat growth and the forest lemma

Simultaneous growth of active components, followed by pruning, gives a factor-2 approximation for generalized Steiner tree/Steiner forest.

Construction and proof obligations

  1. Write cut constraints for separating required terminal pairs.
  2. Raise dual variables of active components uniformly.
  3. Buy a tight edge and merge components.
  4. Prune unnecessary edges; use a contracted-forest degree argument to charge at most twice total dual growth.

At the board

A component is active when it separates at least one still-disconnected demand pair. Growing its dual preserves all edge constraints until the next edge becomes tight.

In the pruned forest, sum degrees of active contracted components and account for inactive components. The argument is an aggregate forest bound; an individual active component can have degree far above two.

Integrate the aggregate crossing bound over growth time to obtain cost(F)≤2∑S yS≤2OPT. Pruning is part of the proof, not an optional optimization.

Examiner task

Reconstruct the dual-fitting calculation during one growth interval. State precisely which components are active, prove the needed degree bound after pruning, and explain why bounding each component’s degree by two is false.

Why cannot one directly reuse the shortest-path equality?

Many demand pairs create branching. A positive cut may be crossed several times, so only aggregate charging survives.

Why is the set of demand pairs important?

Activity is determined by separation of required pairs, not merely by whether a component contains any terminal.

§§8.5–8.6 · Random tree metrics and buy-at-bulk transfer

Random dominating hierarchical tree metrics have expected O(log n) stretch. With careful routing and concave capacity costs, this yields an O(log n) buy-at-bulk approximation.

Construction and proof obligations

  1. Randomize hierarchical partitions by a scale and a permutation.
  2. Bound pair separation at every scale and sum weighted separation probabilities.
  3. Remove auxiliary tree vertices with controlled additional stretch.
  4. Route tree edges through the original graph; use subadditivity of concave nondecreasing costs.

At the board

A cycle metric’s MST is a path: the deleted adjacent pair can have tree distance n−1 while original distance is 1. Randomization over suitable trees controls expected stretch pair by pair.

For a fixed optimal edge-capacity vector c*, linearity gives E[∑e f(c*ₑ)dT(e)]≤O(log n)∑e f(c*ₑ)d(e). No independence between tree distances is needed.

When several tree routes share a graph edge, concavity with f(0)=0 and nondecreasing f gives f(a+b)≤f(a)+f(b), controlling merged capacity cost.

Examiner task

Explain why the MST is not an O(log n)-distortion substitute. Prove how a fixed optimal solution is charged under a random dominating embedding, and identify the assumptions needed to map tree capacities back to graph edges.

Is E[maxpair stretch]≤O(log n) implied?

No. A bound on each pair’s expected stretch does not commute with the maximum.

Why is domination useful?

It prevents the tree objective from underestimating distances when transferring a feasible solution.

§10.1 · Euclidean TSP: dissection, portals, patching and a PTAS

For fixed ε>0, Euclidean TSP in the plane admits a randomized (1+ε) approximation in n·(log n)^{O(1/ε)} time, with success probability at least 1/2 per random dissection; all polynomially many integer shifts may be enumerated.

Construction and proof obligations

  1. Snap and scale to a nice instance, keeping the two-way tour-length perturbation explicit.
  2. Randomly shift a recursive square dissection; place nested portals on each side.
  3. Use the crossing/patching structure theorem: m=O(log n/ε) portals per side and r=O(1/ε) crossings suffice with probability at least 1/2.
  4. Dynamic-program over squares, boundary portal occurrences and entry/exit pairings; merge four children without creating premature cycles.
  5. Shortcut portal visits by the Euclidean triangle inequality, undo snapping and allocate accuracy across the reductions.

At the board

1. Charge moving the input

If each point moves by at most δ, each edge changes by at most 2δ and any n-edge tour by at most 2nδ. Applying this once to the old optimum and once to the returned tour gives C≤(1+η)OPT+(2+η)2nδ.

∣ℓ(T)−ℓ(T′)∣≤2nδ,C≤(1+η)OPT+(2+η)2nδ.|\ell(T)-\ell(T')|\le 2n\delta,\qquad C\le(1+\eta)\mathrm{OPT}+(2+\eta)2n\delta.

2. Allocate the accuracy

Choose the internal scheme error η=ε/4 and ensure 2nδ≤εOPT/8 using a computable geometric lower bound L≤OPT. For 0<ε≤1, total excess is at most εOPT. Handle the zero-diameter input separately.

η+(2+η)ε/8≤ε/4+9ε/32<ε.\eta+(2+\eta)\varepsilon/8\le\varepsilon/4+9\varepsilon/32<\varepsilon.

3. Separate portals from patching

Nested portals discretize crossing positions. The first structure theorem permits r=O(m), giving quasi-polynomial time. The patching lemma bounds r independently of n, which is the decisive improvement.

m=O(η−1log⁡n),r=O(η−1).m=O(\eta^{-1}\log n),\qquad r=O(\eta^{-1}).

4. Derive a probability from expected overhead

The structure proof bounds nonnegative added length by ηOPT/2 in expectation over the shifted dissection. Markov bounds the probability that added length exceeds ηOPT by 1/2.

Pr⁡[Δ>ηOPT]≤EΔηOPT≤12.\Pr[\Delta>\eta\mathrm{OPT}]\le\frac{\mathbb E\Delta}{\eta\mathrm{OPT}}\le\frac12.

5. Preserve connectivity, not only used portals

A state specifies the square, at most r boundary crossing occurrences per side, and their entry/exit pairing. Multiplicity matters. Combine four children by enumerating consistent internal crossings and connections; reject a premature closed component. At the root accept exactly one tour.

6. Count time and amplify

For fixed accuracy the boundary-state enumeration is polynomial in n. Independent repetition makes failure exponentially small in the number of runs; output the cheapest feasible candidate.

T(n)=mO(r)nlog⁡n=n(log⁡n)O(1/η),Pr⁡[all t runs fail]≤2−t.T(n)=m^{O(r)}n\log n=n(\log n)^{O(1/\eta)},\qquad \Pr[\text{all }t\text{ runs fail}]\le2^{-t}.

Examiner task

Reconstruct the Euclidean TSP PTAS. Prove the snapping loss bound, describe a sufficient boundary state and its four-child transition, and distinguish the weaker portal-only running time from the polynomial bound after patching. State the exact structural lemma you invoke and how its expected extra cost yields success probability 1/2.

Why is a subset of boundary portals an insufficient DP state?

Two partial solutions can use the same four portals but pair them as (a,b),(c,d) or (a,c),(b,d). Only one may connect to the outside without a premature cycle. Record multiplicity and connectivity.

Does portal-respecting alone establish a PTAS?

No. Without a constant-in-n crossing bound, the boundary state can be quasi-polynomial. Patching improves r from O(log n/ε) to O(1/ε), while m remains O(log n/ε).

§§16.1, 16.3 · Hardness: gaps, PCP predicates, and approximation conventions

Polynomially many constant-query PCP tests form a constant-arity gap CSP. An approximation beating the NO/YES gap would decide the source NP-hard language.

Construction and proof obligations

  1. Track completeness c, soundness s, random bits r and query count q.
  2. Create one local constraint for each random tape.
  3. Use one global assignment to all proof positions.
  4. Compute the approximation threshold in a stated ratio convention.

At the board

There are 2^r polynomially many tests, each involving at most q proof bits. The proof assignment must be globally consistent across tests.

A maximization ρ-approximation distinguishes YES value at least cM from NO value at most sM only when ρc>s, with strict separation and the small error parameters retained.

The assigned parity-to-3SAT gadget gives values 4 per satisfied parity constraint and 3 otherwise, producing a limiting NO/YES ratio 7/8. The 2SAT gadget’s values 11 and 10 give (10+1/2)/11=21/22.

Examiner task

Turn a PCP with r=O(log n) and q=O(1) into a polynomial gap instance. Derive the 7/8 MAX-E3SAT threshold and the 21/22 MAX-2SAT threshold from the corresponding predicate gadgets. Explain why an exact decision reduction alone does not establish a constant approximation gap.

Why does q=O(1) not mean the raw witness can be sampled?

The PCP theorem supplies an encoded proof with local consistency guarantees. Arbitrary NP certificates lack that property.

Does P≠NP imply every optimization problem is hard to approximate?

No. A suitable gap-preserving reduction is needed for the particular objective and ratio.

Why every interactive proof is in PSPACE

Take an interactive verifier using R random bits and at most a polynomial number of messages, padded to fixed lengths. The prover can see only the public transcript, never the verifier's private random tape. This observation is the delicate part of the upper bound.

State of the dynamic program

For each public transcript h, consider the verifier tapes consistent with it. At a complete transcript, let A(h) count the accepting-consistent tapes. Define a backward recursion Val(h) on transcript prefixes.

Terminal: Val(h)=A(h)Prover turn: Val(h)=maxaVal(ha)Verifier turn: Val(h)=∑bVal(hb)

Proof of correctness

Induct backwards on the number of remaining messages. At a prover node all random tapes sharing a visible transcript must receive the same prover message, so one takes a maximum over messages. At a verifier node the next public message partitions the consistent tapes into disjoint classes, so one sums their optimal continuation counts. At a leaf one counts accepting tapes by enumeration. It follows that Val(ε)/2R is exactly the maximum acceptance probability over prover strategies.

Space bound

The recursion depth, transcript length, and counter bit length are polynomial in the input size. Enumerating exponentially many messages and random tapes costs time but not more than polynomial space. Depth-first evaluation therefore decides the language in polynomial space.

Common incorrect proof. Maximising separately for each verifier random string lets the prover learn private coins. The correct recursion maximises only over messages that depend on the public transcript.

Definitions, quantifiers, and amplification

An interactive proof for LL is a probabilistic polynomial-time verifier VV interacting for polynomially many rounds with an unbounded prover. With the standard constants, x∈L⇒∃Pℙ[(P,V)(x) accepts]≥23,x\in L\Longrightarrow \exists P\quad \mathbb P[(P,V)(x)\text{ accepts}]\geq\tfrac23, x∉L⇒∀P*ℙ[(P*,V)(x) accepts]≤13.x\notin L\Longrightarrow \forall P^*\quad \mathbb P[(P^*,V)(x)\text{ accepts}]\leq\tfrac13. The order ∃P\exists P in completeness and ∀P*\forall P^* in soundness is essential. A proof has soundness against computationally unbounded provers; an argument need only resist polynomial-time cheating provers.

Sequential repetition followed by majority reduces both errors exponentially; fresh verifier randomness is required. Public-coin protocols expose each random challenge. Private coins do not increase the power of polynomial-round interactive proofs (Goldwasser–Sipser), although the conversion is not the content of the four main articles. In classical 𝖬𝖨𝖯\mathsf{MIP}, two or more all-powerful provers agree on a strategy before the protocol but cannot communicate after receiving their questions. Their answers must therefore be marginals of fixed global strategy functions. This noncommunication is the extra resource: with one prover, every claimed value can be adapted to the whole transcript; a second prover can be asked a correlated question that tests consistency with one global object.

𝖬𝖨𝖯⊆𝖭𝖤𝖷𝖯\mathsf{MIP}\subseteq\mathsf{NEXP}

Fix the input. A deterministic strategy for each prover is a table mapping its polynomial-length local transcripts to polynomial-length answers. There are at most 2poly(n)2^{\operatorname{poly}(n)} entries. A nondeterministic exponential-time machine guesses all tables, enumerates all polynomial-length verifier random strings, simulates the protocol, and counts acceptance exactly. If randomized provers helped, fixing their private coins would leave some deterministic strategy with at least the same acceptance probability. Hence 𝖬𝖨𝖯⊆𝖭𝖤𝖷𝖯\mathsf{MIP}\subseteq\mathsf{NEXP}.

𝖭𝖤𝖷𝖯⊆𝖬𝖨𝖯\mathsf{NEXP}\subseteq\mathsf{MIP}: proof architecture

An 𝖭𝖤𝖷𝖯\mathsf{NEXP} computation has an exponentially long tableau or witness, while every location still has a polynomial-length address. The lower-bound proof has four separate stages.

  1. Encode the accepting computation by a Boolean function on m=poly(n)m=\operatorname{poly}(n) address bits and extend it to the unique multilinear polynomial over a sufficiently large finite field.

  2. Arithmetize the local transition constraints. A false tableau makes the resulting constraint polynomial nonzero; an LFKN-style reduction turns the claim that its global sum is zero into claims about values at random points.

  3. Replace trusted oracle access by two noncommunicating provers. Correlated questions compare their answers, while the multilinearity test checks that the alleged value table behaves like one multilinear function rather than unrelated answers chosen separately at each query.

  4. For soundness, first condition on passing the multilinearity and consistency tests. The answers are then close to evaluations of a single multilinear polynomial. If no accepting tableau exists, the arithmetized constraint is nonzero, so the random algebraic check catches the lie with constant probability. Standard repetition reduces the remaining error.

The essential role of the second prover is therefore not extra computation: it is the enforcement of one globally consistent function behind locally requested values. This yields 𝖬𝖨𝖯=𝖭𝖤𝖷𝖯.\boxed{\mathsf{MIP}=\mathsf{NEXP}.}

Warm-up: graph isomorphism

For isomorphic G0,G1G_0,G_1, the prover sends a random relabeling HH of one graph. The verifier sends a challenge b∈{0,1}b\in\{0,1\}, and the prover opens an isomorphism Gb≅HG_b\cong H. A simulator guesses bb, constructs HH from GbG_b, runs V*V^*, and rewinds unless its challenge equals the guess. Each attempt succeeds with probability 1/21/2, and conditioned on success the transcript has the correct distribution. Rewinding is the central simulation technique.

The GMW protocol for 3-colouring

Let c:V→{1,2,3}c:V\to\{1,2,3\} be a proper colouring and let the commitment scheme be hiding and binding.

  1. The prover chooses a random permutation π\pi of the three colours and commits separately to every value π(c(v))\pi(c(v)).

  2. The verifier chooses a uniformly random edge uvuv.

  3. The prover opens only the two endpoint commitments; the verifier checks that the openings are valid and the colours differ.

Perfect completeness is immediate. If the graph is not 3-colourable, every fixed committed assignment has a monochromatic edge; binding prevents changing it after the challenge. A round therefore rejects with probability at least 1/|E|1/|E|, and sequential repetition gives constant or negligible soundness error.

For a malicious verifier V*V^* with arbitrary auxiliary input, the simulator uses the following rewinding experiment.

  1. Guess an edge e=uve=uv uniformly from EE and choose an ordered pair of distinct colours uniformly from the six possibilities.

  2. Commit to those colours at u,vu,v and commit to arbitrary dummy colours at all other vertices; run V*V^* on these commitments with a fixed sampled random tape.

  3. If V*V^* asks for an edge different from ee, discard the attempt and restart. Otherwise open the two commitments and output the complete view.

For the honest verifier, the guessed edge matches with probability exactly 1/|E|1/|E|. For a malicious V*V^*, its challenge may depend on the commitment string, so exact uniformity must not be assumed. Instead, computational hiding makes the challenge distribution computationally insensitive to which edge was prepared. The success probability is therefore inverse-polynomial, up to a negligible term, and rewinding has expected polynomial running time (with the standard cutoff if one wants a strict polynomial-time simulator). Conditioned on success, the opened ordered pair is uniform over the six distinct colour pairs, exactly as for a uniformly permuted proper colouring. The unopened commitments need not encode a global colouring; a hybrid argument using computational hiding replaces their dummy messages one at a time by the real committed colours. Thus the simulated and real views are computationally indistinguishable. Binding, separately, prevents a cheating prover from adapting endpoint colours after seeing the edge. Via reductions to 3-colouring, GMW obtains zero-knowledge proofs for all of 𝖭𝖯\mathsf{NP} from the stated commitment/encryption assumption.

Do not conflate properties. Binding supports soundness; hiding supports zero knowledge. Zero knowledge does not mean that the verifier learns nothing at all—it learns that the statement is true. Sequential composition is the safe default under standard hypotheses; arbitrary parallel repetition need not preserve zero knowledge.

The distinction between ordinary and induced copies is essential: edge-monotone properties use ordinary removal; hereditary properties require induced removal.
