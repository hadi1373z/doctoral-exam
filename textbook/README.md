# Textbook reader and four exam summaries

Open the [mathematical textbook](index.html) or use the deployed [GitHub Pages reader](https://hadi1373z.github.io/doctoral-exam/textbook/).

This adds a long-form mathematical reading layer to the original Doctoral Exam Studio without removing the existing 50 interactive lessons, visual proof labs, question banks, oral simulations or expertise tracking.

## Four source drafts

- [Research statement](summaries/01_research_statement_hadi_zamani.tex)
- [Approximation algorithms — Williamson & Shmoys](summaries/02_approximation_algorithms_summary_hadi_zamani.tex)
- [Interactive proofs — LFKN, Shamir, BFL and GMW](summaries/03_interactive_proofs_summary_hadi_zamani.tex)
- [Probabilistic method — Alon & Spencer, Chapters 6, 7, 15 and 17](summaries/04_probabilistic_method_summary_hadi_zamani.tex)

These four original files are included **byte-for-byte**, including their original dates and theorem inventories. The browser reader contains a navigable HTML/MathML version and new textbook-style introductions and worked proofs. Its conversion-only normalization of LaTeX does not change any original draft.

## Design and behaviour

- Independent offline reader with no CDN or account requirement; formulas are native MathML.
- Sidebar volumes, clickable section contents, section-title search, font controls and browser printing.
- Reading markers are local and **do not** count as oral-exam mastery evidence.
- Source text is navigable by section; long-form theorem inventories and proofs are maintained.
- Interactive lessons, question bank, visual proofs and expertise map remain in the root application.
- Seventeen chapter companions connect the full text to the [continuous lecture course](../#learn), with worked examples, visual proof inferences and examiner extensions. The four original source drafts remain unchanged.

For PDF handouts, use **Print** in the reader or compile the original `.tex` files with LaTeX. The main site is a static GitHub Pages deployment.
